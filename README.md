# Zylvora Technologies - Enterprise Digital & ERP Transformation Website

Next-Generation Enterprise ERP Solutions, SAP S/4HANA Implementations, Cloud Architecture, and Data Intelligence platform.

## 🚀 Live Static Preview
The static HTML preview version is located in the `/preview` directory and is 100% compatible with GitHub Pages, Vercel, and Netlify.

- **Direct Entry:** `preview/index.html`
- **Total Pages:** 27 fully linked enterprise pages
- **Assets:** Tailwind CSS CDN, interactive canvas animations, dark-themed Google Maps, high-resolution enterprise imagery, and local MP4 hero background stream.

## 🛠️ Tech Stack
- **Backend / Template Engine:** PHP 8+ (Dynamic modular architecture)
- **Frontend / Styling:** HTML5, Modern CSS3 Glassmorphism, Tailwind CSS, Material Symbols & Heroicons
- **Scripts:** Vanilla JavaScript (Particle Neural Canvas, Stats Counter, Mobile Drawer Navigation, Lead Capture Validation)
- **Server:** Apache / XAMPP compatible with clean `.htaccess` rewrites

## 📁 Project Structure
- `index.php` / `preview/index.html` - Enterprise Hero & Showcase
- `includes/` - Modular PHP headers, footers, navigation, and configurations
- `services/` - 1. Services (ERP, Cloud, Security, Data Solutions)
- `sap/` - 2. SAP Practice (Consulting, Migration, Implementation, Support, EWM, Hybris)
- `industries/` - 3. Industries (Manufacturing, Services, Retail, Education, Public Sector)
- `erp-delivery/` - 4. ERP Delivery (Odoo, Zoho ERP, Freshdesk)
- `about.php` & `careers.php` - Corporate overview and talent acquisition
- `contact.php` - 5. Interactive Contact Page with Dark Google Maps iframe
- `export_preview.php` - Generator script to compile PHP pages into standalone static HTML files

## 💻 Local PHP Development (XAMPP)
1. Place project in `C:/xampp/htdocs/Zylvora`
2. Start Apache via XAMPP Control Panel
3. Visit: `http://localhost/Zylvora/`
